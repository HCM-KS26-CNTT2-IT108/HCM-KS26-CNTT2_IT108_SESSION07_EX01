PHẦN 1: PHÂN TÍCH LỖI

1. Trace code và nguyên nhân file daily_critical.txt bị trống:
- Dòng 1: Script ghi tiêu đề "=== Bat dau quet log: ... ===" vào file daily_critical.txt.
- Dòng 2: Lệnh `Select-String -Path server.log -Pattern "critical" -CaseSensitive` thực hiện quét file log. Do có tham số `-CaseSensitive`, lệnh này bắt buộc tìm kiếm chính xác chuỗi ký tự thường "critical".
- Trong file `server.log`, các từ chỉ mức độ lỗi được ghi ở dạng chữ hoa hoàn toàn (`CRITICAL`). 
- Do sự bất đồng về chữ hoa/thường kết hợp với cờ `-CaseSensitive`, lệnh không khớp được bất kỳ dòng nào, dẫn đến kết quả trả về rỗng và nội dung log lỗi bị bỏ trống trong file daily_critical.txt.


PHẦN 2: SỬA LỖI VÀ KIỂM THỬ

1. Đoạn script sau khi đã được sửa đúng:
# Script: deploy_checker.ps1 (Đã sửa lỗi)
"=== Bat dau quet log: $(Get-Date) ===" | Out-File daily_critical.txt
Select-String -Path server.log -Pattern "CRITICAL" | Out-File -Append daily_critical.txt
"=== Hoan tat. So dong loi: ===" | Out-File -Append daily_critical.txt
(Get-Content daily_critical.txt).Count | Out-File -Append daily_critical.txt

2. Kết quả mong đợi của file daily_critical.txt sau khi script chạy đúng:
=== Bat dau quet log: 10/12/2026 15:35:00 ===
server.log:2:2026-09-18 02:30:11 CRITICAL Database connection pool exhausted
server.log:3:2026-09-18 02:30:45 CRITICAL Retry limit exceeded for payment-service
=== Hoan tat. So dong loi: ===5

3. Điều gì xảy ra nếu file server.log không tồn tại?
- Nếu file `server.log` không tồn tại, cmdlet `Select-String` trong PowerShell sẽ không thể tìm thấy đường dẫn và ngay lập tức văng lỗi ngoại lệ (exception) màu đỏ trên màn hình Terminal (thông báo file không tìm thấy - File Not Found). 
- Quá trình thực thi script sẽ bị gián đoạn/ngưng lại tại thời điểm đó, và file `daily_critical.txt` sẽ chỉ ghi lại được dòng tiêu đề khởi đầu chứ không hoàn thành được các bước tiếp theo.
